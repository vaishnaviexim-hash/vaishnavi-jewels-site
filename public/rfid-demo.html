Vendor demo Vaishnavi Jewels, Surat · RFID and barcode tag test · 20 made-up pieces, no prices, not linked to the real stock system

This page proves three things for each of the 20 test tags: the printed barcode and QR scan, the RFID chip reads, and both point to the same piece.

Steps

  1. Print the 20 labels. Open Print labels and download the label PDF (one 100 × 15 mm page per tag, the same roll size as our Ornate tags: 70 mm print area + 30 mm tail on the right). The 70 mm print area folds in half; nothing crosses the fold and nothing prints on the tail. Print at 100% / actual size, no scaling.
  2. Encode the chips. Write each tag's EPC exactly as listed under Tags or on the A4 vendor sheet: 96-bit, 24 hex characters, EPC bank from word 2, PC word 3000. Example: A0000001 → 000000004130303030303031.
    • If you would rather keep your factory EPCs, that is fine: the Scan test links them to the right tag (step 6).
  3. Set up DataWedge on the Zebra TC22R. Open DataWedge → create a profile (for example "VJ demo") → Associated apps: com.android.chrome / *.
    • Barcode input: on, with Code 128 and QR Code enabled.
    • RFID input: on. Tag read mode: Single. Lower the antenna transmit power (start near 10 dBm) so only the tag on top of the reader is read, not the whole tray.
    • Keystroke output: on. Basic data formatting: Send data on, Send ENTER key on, for both the barcode and the RFID plugin. No prefix, or the AIM code ID if you want the page to tell QR from Code 128 by itself.
    • If characters go missing, set an inter-character delay of 10–20 ms.
    Other readers work the same way: any scanner or RFID reader in keyboard (HID / wedge) mode that types the value and presses Enter. A Zebra RFD40 sled must be in HID keyboard mode; browsers cannot talk to it over Bluetooth directly.
  4. Open Scan test in Chrome on the TC22R. The big box takes the scans; the on-screen keyboard stays hidden so the list is visible. Tap Type if you want to enter a value by hand.
  5. Scan all 20 QR codes. Choose QR above the box first so each code is ticked in the right column (the flap is too small for a 1D barcode). Each good scan beeps and turns green.
  6. Read all 20 RFID chips, one tag at a time, close to the reader. With factory EPCs, scan a tag's barcode and its chip one after the other (either order, within 20 seconds): they link automatically. A chip read on its own can still be linked by hand from the list under the checklist.
  7. Read the totals. A pass is QR 20/20 · RFID 20/20 · Linked 20/20. Anything unknown or repeated is listed under the checklist. Download the results CSV and send it to Vaishnavi Jewels.

No phone handheld? Use Photo scan on the Scan test page: take a photo of a label and the page reads the barcode and QR from it (works in Chrome on Android and in Safari on iPhone).
